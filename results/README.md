# Smoke test çıktıları

Bu dizin canlı model yanıtları, hata ayrıntıları, token kullanımı ve zaman ölçümlerini içerebilir. Ham sonuçlar yerel inceleme içindir; `.gitignore` tarafından Git commit'lerinden hariç tutulur.

`summary.json` gibi kimlik bilgisi içermeyen özetler bile gerçek sağlayıcı/model adları ve deney metadatası taşıyabileceğinden yayınlanmadan önce ayrıca gözden geçirilmelidir. API anahtarları hiçbir sonuç dosyasına yazılmaz.
