# Evaluation run artifacts

Bu dizin mock dry-run ve ilerideki kontrollü evaluation çıktıları içindir.

- Gerçek model yanıtları hassas olabilir; yayınlanmadan önce redaksiyon ve erişim kontrolü gerekir.
- API anahtarları, tokenlar veya kişisel veriler bu dizinde tutulmamalıdır.
- `mock-dry-run/` yalnızca ağsız ve sentetik mock yanıtlar içerir.
- Büyük veya gerçek evaluation çıktıları varsayılan olarak GitHub’a commit edilmemelidir.
